RIT Dorm Laundry Tracker

My first team prototype for checking dorm washers and dryers before walking downstairs

  • HTML
  • CSS
  • Vanilla JavaScript
  • localStorage
  • JSON data modeling

October–December 2024 · RIT SWEN 101 team project

  • Repo
What it is
A prototype website where RIT students pick their dorm, see which washers and dryers are free, and start a 55-minute laundry timer.
Why I made it
It was our team project for SWEN 101: check if a machine is free before you walk downstairs.
What I did
I worked with my team to plan the app, split up the pages, share our code and put it all together, in plain HTML, CSS and JavaScript.
How it turned out
It was only a front end, not connected to real machines, but it was my first real team project, and it's where I met my friend Jimmy.

The details

My first team experience

The most important part of this project for me was learning how to work on software with a team for the first time. We had to agree on what the app should do, divide up the pages and features, share our code, and bring it all back together into one flow.

It was a great intro to working with people instead of building everything alone. I also met my friend Jimmy through this project, and we're still friends today.

Choosing a dorm

It starts with a simple RIT email login and then asks you to pick one of thirteen residence halls. The dorm you pick is saved in localStorage and carried over to the machine page.

Availability and timers

Free washers and dryers have a green outline, and machines in use have a red one. Picking a free machine opens a status page with a 55-minute countdown.

It was only a front end, not hooked up to anything on campus. We designed a JSON layout for thirteen dorms with eight machines each, but the final pages still had the machine states hardcoded, and the timer reset if you refreshed the page.
